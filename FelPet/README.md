# FelPet
Projeto construído em React Native com base nas instruções fornecidas em sala de aula para entrega da recuperação obrigatória da matéria de Programação de Aplicativos Mobile II, referente ao 3ºBimestre. O objetivo principal é avaliar a capacidade de produção de um sistema mobile com integração ao sistema de autenticação do Firebase e notificações do React Native.
